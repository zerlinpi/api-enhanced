# 音乐人作品发现社区（独立 MVP）

该目录是 **独立试验性 Web 应用**，不会修改或启动主仓库现有网易云 API 路由。

## 运行

要求 Node.js 18+，不需要额外安装依赖：

```bash
node artist-community/server.js
```

打开 http://localhost:3100 。支持 `ARTIST_COMMUNITY_PORT` 修改端口，以及 `ARTIST_COMMUNITY_DATA` 指定存储文件位置（默认仓库根目录 `.artist-community-data.json`）。

## 已实现

- 投稿网易云歌曲 URL（规范化 ID、防止同歌曲重复提交）。
- 作品大厅、跳转网易云官方歌曲页面。
- 浏览器生成随机访客 ID，重复访问同一作品只计一次站内访客；**不证明不同自然人身份**。
- 独立 JSON 存储、原子替换、基础输入检查。
- 会员任务状态始终明确显示“未接入”，**不将站内访问解释为官方有效播放**。

## 后续正式上线之前必须完成

1. 引入平台用户注册、登录、作品所有权验证、审核与速率限制。
2. 将 JSON 替换为 PostgreSQL，并进行备份、并发事务处理。
3. 对接网易云正式授权的数据源；禁止直接在浏览器存储网易云 Cookie/密码。
4. 若取得权限，记录官方任务原始快照、同步时间、字段来源和错误状态；未授权时保持不可用。
5. 引入反垃圾、隐私与数据删除流程、日志审计、自动化测试。
6. 核查第三方 API 使用授权和音乐平台服务规则。

**安全边界：** 这是歌曲发现社区，不是自动互刷播放量工具。无后台播放器、账号托管、Cookie 抓取或官方有效播放伪造。
